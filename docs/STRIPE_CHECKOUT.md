# Stripe sandbox checkout

`./stripe` exports a server-side adapter using pinned official Stripe SDK 23.1.0/API 2026-10-28.endive. It accepts test-mode keys only. No live payment enablement, Connect payout routing, refund automation or creator accounting is implied.

Configure `STRIPE_SECRET_KEY` with an `sk_test_` key through secure environment settings, not source control or chat. A restricted `rk_test_` key needs read access to Account and read/write Checkout Sessions. Configure `STRIPE_WEBHOOK_SECRET` from a sandbox webhook endpoint subscribed to `checkout.session.completed` at the pinned API version. Supply the expected account ID, public HTTPS return origin, and an explicit merchant authorizer that checks the merchant owns the complete work and is entitled to receive this account's proceeds. Multi-merchant payouts require an additional Connect integration; never authorize unrelated artists against the platform account by default.

Construct the actual DAE CheckoutEngine with `STRIPE_CHECKOUT_QUOTE_MS` (31 minutes). Its quote is still capped by product expiry. Stripe requires at least 30 minutes, so products expiring sooner fail closed rather than silently receiving an extended quote. Bind `provider` and `verifier` to that engine. Set WholeWorkCommerce `presentPendingOrder` to `presentationForOrder` and `paymentOrigins` to `['https://checkout.stripe.com']`. The payment URL is a private capability and must be returned only through the authenticated encrypted client boundary.

The raw webhook route must pass original request bytes and the `stripe-signature` header to WholeWorkCommerce.settle; do not parse or reserialize first. Bound raw payload to 65536 bytes, omit it from logs, and acknowledge success only after durable settlement. Failures must receive a retryable status. Official SDK signature verification, test mode, account session retrieval, version, amount, currency, buyer, product digest and expiry binding are mandatory. Redirect success is never settlement authority. Required financial identifiers and quote metadata are disclosed to Stripe; protected media, private manifests, content keys and card details never pass through this adapter.

`tests/stripe-checkout.test.mjs` verifies official SDK raw signatures and composes the actual durable DAE CheckoutEngine with a mocked sandbox transport, including restart and duplicate delivery. These are automated fixtures, not evidence of a real Stripe account or successful real charge. `scripts/inspect-stripe-sandbox.mjs` performs a read-only account check when a secure test key is available. Sandbox webhook delivery and browser payment still require configured credentials and an actual deployed endpoint.
